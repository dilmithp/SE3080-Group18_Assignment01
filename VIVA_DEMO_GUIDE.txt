SECTION 2 — NEW THIS SESSION, CODE VERIFIED, DO A 2-MIN LIVE CHECK FIRST
--------------------------------------------------------------------------------
All of these pass `flutter analyze` (0 issues) and the full test suite (288
tests) and the app builds clean with them — but nobody has watched them run
on a real device yet. Check each once before relying on it live.

- LANGUAGE SWITCHING (English / Sinhala / Tamil):
  Profile → Accessibility (or Home → Accessibility panel → full settings) →
  Language card → tap it → pick Sinhala or Tamil → screen text should change
  immediately. This is the headline new feature — test it first.

- VOICE-GUIDED PROMPTS (text-to-speech):
  Accessibility Settings → turn on "Voice-Guided Prompts" → device should
  speak "Voice-Guided Prompts" out loud. Needs a device/emulator with a TTS
  engine and the volume up. If it stays silent, don't dwell on it live —
  say it's wired and move on.

- REDUCED MOTION / DATA SAVER toggles:
  Accessibility Settings → two new switches under "Display & Layout" and
  "Assistance & Audio". Reduced Motion turns off app animations; Data Saver
  has no visible effect yet (it's a flag other screens can read later) — if
  asked, say it's the hook for a future image-compression feature.

- OFFLINE BANNER:
  Turn off Wi-Fi/data on the device → within ~5 seconds a red "You are
  offline" banner should appear at the top of the screen → turn data back on
  → it disappears within ~5 seconds. Good one to demo deliberately — it's
  visual and simple.
